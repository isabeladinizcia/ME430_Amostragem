A média de leitos (\(\mu\)) é 706.25, \(\sigma^2\) é 86549.94 e \(S^2\) é 98914.21.

Considerando o plano \(AAS_s\) com amostra de tamanho \(n\), vimos que a média amostral, \(\bar{y}\), é um estimador não viesado para \(\mu\) e sua variância amostral teórica é \(Var(\bar{y})=(1-f)\frac{S^2}{n}\), em que \(f=\frac{n}{N}\) é a fração amostral.

# ITEM 5 — Distribuição da média amostral para n = 2 (6 pontos)
# Liste todas as combinações possíveis de 2 hospitais. Para cada amostra,
# calcule a média de leitos e sua probabilidade. Organize o resultado no objeto
# `distybar` com as colunas dos dois hospitais, `ybar` e `prob`.
# Dica: use `combinat::combn()`, `apply()` e a população armazenada em `data`.

# Escreva seu código abaixo.


HospitalA = character(amostrasDif)
HospitalB = character(amostrasDif)
ybar = numeric(amostrasDif)
prob = numeric(amostrasDif)

count = 0
for (i in 1:N){
    for (j in 1:N){
        if (i < j){
            count = count+1
            HospitalA[count] = as.character(data$Hospital[i])
            HospitalB[count] = as.character(data$Hospital[j])
            ybar[count] = ((data$Leitos[i]) + (data$Leitos[j]))/2
            prob[count] = 1/amostrasDif
        }
    }
}

if(count != amostrasDif){
    print("Problema!")
}

distybar <- data.frame(
  HospitalA = HospitalA,
  HospitalB = HospitalB,
  ybar = ybar,
  prob = prob
)

Comparando os dois planos de amostragem, observa-se que a esperança da média amostral permanece próxima da média populacional, sendo 706.25 para (n=2) e 706.25 para (n=4). Isso mostra que a média amostral apresenta comportamento não viesado em relação à média populacional.

Já a variância diminui quando o tamanho da amostra aumenta. Para (n=2), a variância da média amostral é 37092.83, enquanto para (n=4) é 12364.28. Portanto, ao aumentar o tamanho da amostra de 2 para 4 hospitais, a média amostral apresenta menor variabilidade.

Esse comportamento também pode ser observado nos histogramas: para \(n=4\), os valores de \(\bar{y}\) ficam mais concentrados em torno da média populacional \(\mu\), enquanto para \(n=2\) a distribuição é mais dispersa. Assim, o aumento do tamanho da amostra reduz a variância da média amostral e torna suas estimativas mais concentradas em torno de \(\mu\).
